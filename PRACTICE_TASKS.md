# Practice Tasks

Choose one for each PR practice round.

## Task A: Friendly Greeting

- Update `greet(name)` so empty input returns `"Hello, anonymous!"`.
- Add or update tests for the new behavior.

## Task B: Excited Greeting

- Add `greetLoud(name)` that returns an uppercase greeting.
- Add tests for both normal and empty-name input.

## Task C: PR Description Practice

- Keep code unchanged.
- Open a docs-only PR improving `README.md` clarity.
- Fill out the PR template with a detailed test plan.
